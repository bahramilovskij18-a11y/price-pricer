# 📊 Приложение учета устройств для Telegram

Красивое Telegram Web App для управления историей покупки и продажи устройств в стиле Apple.

## 🎨 Особенности

- ✨ Минималистичный дизайн в стиле Apple
- 📱 Полностью адаптивный интерфейс
- 💾 Автосохранение данных в localStorage
- 🌙 Светлая тема с плавными переходами
- 📈 История покупок и продаж
- 🎯 Калькуляция прибыли/убытка

## 📋 Требования

- Python 3.9+
- aiogram 3.x
- python-dotenv

## 🚀 Установка и запуск

### 1. Клонирование и подготовка

```bash
cd Price_Pricer
pip install -r requirements.txt
```

### 2. Конфигурация

Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=your_telegram_bot_token
WEB_APP_URL=https://yourdomain.com
```

### 3. Развертывание веб-приложения

Веб-приложение нужно разместить на HTTPS сервере. Вариант:

- **Ngrok** (для тестирования):
  ```bash
  ngrok http 8000
  ```

- **Собственный сервер** (рекомендуется):
  - Скопируйте `index.html`, `styles.css`, `app.js` на свой сервер
  - Убедитесь, что сервер использует HTTPS

### 4. Запуск бота

```bash
python bot.py
```

## 📱 Использование

1. Найдите бота в Telegram
2. Нажмите `/start`
3. Нажмите кнопку "📊 Открыть приложение"
4. Заполните форму и добавляйте записи

## 💡 Особенности интерфейса

### Левая панель - История
- Список всех записей о покупках/продажах
- Цветовое обозначение типа операции
- Кликните на запись чтобы удалить

### Правая панель - Форма
- **Группа** - выбор из предложенных вариантов
- **Устройство** - название товара
- **Покупка/Продажа** - цены операций

## 🔐 Безопасность

- Данные хранятся только в localStorage браузера
- Для синхронизации между устройствами используйте backend
